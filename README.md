# Gas-Price-Prediction
# ⛽ Gas Price Forecasting with SARIMA and Prophet

This project predicts gas prices using time series forecasting models — **SARIMA** and **Prophet** — implemented entirely in a **Google Colab notebook**. The models analyze historical gas price data to project future trends, enabling better planning and decision-making.

---

## 📌 Overview

Gas prices are influenced by seasonal, economic, and geopolitical factors. This notebook-based project applies:

- **SARIMA**: Captures both seasonal and non-seasonal trends in time series data.
- **Prophet**: A forecasting model by Meta (Facebook) that is intuitive, robust, and handles seasonality, holidays, and outliers well.

The goal is to compare both models on forecasting accuracy and visualization clarity.

---

## 📒 Notebook Features

- 📊 **Data Preprocessing**: Load and clean historical gas price data
- 🔍 **Exploratory Data Analysis (EDA)**: Visualize trends and seasonality
- 📈 **SARIMA Model**: Manual parameter tuning with seasonal decomposition
- 🧠 **Prophet Model**: Minimal configuration with automatic seasonality detection
- 📉 **Evaluation**: Compare MAE, RMSE, and visual accuracy
- 📌 **Forecast Plots**: Actual vs predicted trends with confidence intervals
